# 🛡️ Android Privacy & Security Scanner

A native Android application built in Kotlin that scans user-installed applications to detect sensitive permission risks.

## 🚀 Features
* **Permission Risk Analysis:** Scans for sensitive permissions: Camera, Microphone, Fine Location, and Contacts.
* **System App Filtering:** Excludes system apps to avoid false positives and focus on third-party security.
* **Clean Architecture:** Modern Kotlin implementation utilizing Android Package Manager APIs.

## 🛠️ Tech Stack
* **Language:** Kotlin
* **UI:** XML Layouts
* **IDE:** Android Studio
* **Build System:** Gradle (Kotlin DSL)
